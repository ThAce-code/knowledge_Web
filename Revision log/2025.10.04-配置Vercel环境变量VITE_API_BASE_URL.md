# 配置 Vercel 环境变量 VITE_API_BASE_URL

作者：CodeBuddy 和 刘宇航  
日期：2025-10-04

## 任务目标
在 Vercel 项目中设置环境变量 `VITE_API_BASE_URL`（区分 Preview/Production），保证 apiClient 请求前缀正确。

## 操作步骤
1. 在仓库根目录参考 `.env.example` 设置本地环境（如需）。  #  
2. 打开 Vercel Dashboard → Project → Settings → Environment Variables。  #  
3. 新增变量：  
   - Name: `VITE_API_BASE_URL`  #  
   - Value: 你的 API 前缀（例如 `https://api.example.com`）  #  
   - Environment: 选择 Preview 和 Production 分别配置  #  
4. 保存后重新部署。  #  

## 验收指引
- 部署环境访问站点，打开浏览器 DevTools：  #  
  - Network 中接口请求的 URL 应以 `VITE_API_BASE_URL` 为前缀  #  
  - Console 无因空前缀导致的错误（例如 `HTTP 404`）  #
