# 配置静态资源长缓存

作者：CodeBuddy 和 刘宇航  
日期：2025-10-04

## 任务目标
在 Vercel 上为构建产物与静态资源启用长缓存，同时确保 HTML 不被长缓存。

## 变更内容
- 更新 vercel.json：新增 headers  
  - /assets/* 与常见静态扩展名设置 `Cache-Control: public, max-age=31536000, immutable`  #  
  - /index.html 设置 `Cache-Control: no-cache`  #  

## 验收指引（部署到 Vercel 后）
- 通过浏览器 DevTools 检查静态资源响应头：应包含长缓存策略  #  
- index.html 响应头不含长缓存（no-cache）  #  
- 页面功能正常，无缓存导致的更新异常  #
