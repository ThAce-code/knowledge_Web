# 内容与索引分片优化

作者：CodeBuddy 和 刘宇航  
日期：2025-10-04

## 任务目标
优化内容原文加载与构建分块，降低主包体积并移除 glob 弃用警告。

## 变更内容
- src/utils/contentLoader.js：将 `import.meta.glob(..., { as:'raw' })` 改为 `{ query:'?raw', import:'default', eager:false }` 以符合新 API 且显式懒加载  #  
- vite.config.js：新增 `build.rollupOptions.output.manualChunks`，将 React/Router 与 Markdown/Katex 生态拆分，降低主包体积  #  

## 验收建议
- 运行 `npm run build` 查看不再出现 as:'raw' 弃用提示，主包体积下降（vendor 分块化）  #  
- 页面功能与 Markdown/KaTeX 渲染保持正常  #  

## 后续优化（可选）
