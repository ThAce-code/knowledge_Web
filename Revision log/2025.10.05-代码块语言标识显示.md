# 代码块语言标识显示功能
- 时间：2025-10-05
- 变更文件：
  - src/components/DynamicKnowledgeDetails.jsx：为代码块添加语言标签显示
  - src/styles/DetailsPage.css：新增 .code-lang 样式

## 功能说明
- 当 Markdown 代码块指定语言时（如 ```javascript、```python），在左上角显示语言名称
- 右上角保持复制按钮，按语言显示中英文文案
- 无语言标注的代码块不显示语言标签

## 使用示例
```javascript
// 会显示 "javascript" 标签和 "copy" 按钮
const hello = 'world';
```

```
// 无语言标注，只显示 "复制" 按钮
普通代码块
```

## 样式特点
- 语言标签：左上角，半透明背景，小写显示
- 复制按钮：右上角，渐变背景，悬浮效果
- 两者不重叠，保持代码块整洁美观
