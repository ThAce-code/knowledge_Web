# 启用 rehype-raw 支持 Markdown 内嵌 HTML
- 时间：2025-10-05
- 变更文件：src/components/DynamicKnowledgeDetails.jsx
- 改动：
  - 引入 `rehype-raw` 并将 `rehypePlugins` 更新为 `[rehypeRaw, rehypeKatex]` 以支持 Markdown 中的 HTML（例如表格）。
- 影响范围：仅 Markdown 渲染；不影响 GFM、Math、KaTeX、目录与样式。
- 风险与注意：
  - `rehype-raw` 会解析内嵌 HTML，请确保内容来源可信；若后续需要更严格约束，可加入 `rehype-sanitize` 并配置允许的标签（table、thead、tbody、tr、th、td 等）。
