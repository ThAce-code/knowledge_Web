# 代码块一键复制功能
- 时间：2025-10-05
- 变更文件：
  - src/components/DynamicKnowledgeDetails.jsx
  - src/styles/DetailsPage.css
- 主要改动：
  - 在 ReactMarkdown 的代码渲染器为非行内代码添加 CopyButton（Clipboard API），按钮显示“复制/已复制”。
  - CSS 为 .code-block 增加 position: relative 与顶部间距，并新增 .copy-btn 样式。
- 使用方式：文章中的 ``` 代码块将自动出现“复制”按钮；点击后复制代码文本到剪贴板，1.5s 内状态变为“已复制”并自动还原。
- 风险与注意：需 HTTPS 环境以保证 Clipboard API 正常；如浏览器权限限制，控制台会输出错误日志。
