# 变量、常量与数据类型详解

在编程中，变量、常量和数据类型是最核心的基础概念。理解它们有助于编写可靠、可读且高效的代码。

## 1. 变量（Variable）
变量用于存储可变的数据值，在程序运行过程中可以被重新赋值。

示例（C语言）：
```c
int age = 20;     // 定义整型变量
age = 21;         // 变量可被重新赋值
```

- 命名规则：以字母或下划线开头，区分大小写
- 作用域：变量在其声明的作用域内有效（块级、函数级、文件级）

## 2. 常量（Constant）
常量是不可变的值，定义后不可更改。使用常量可以提高代码的安全性与可读性。

示例（C语言）：
```c
const float PI = 3.14159f;  // 常量，禁止修改
#define MAX_SIZE 1024       // 宏常量（编译期替换）
```

- const：类型检查更严格，受作用域控制
- 宏常量：在预处理阶段替换，没有类型信息

## 3. 基本数据类型（Data Types）
数据类型用于描述内存中的数据格式与大小，决定运算行为与存储方式。

常见基本类型（以 C 为例）：
| 类型         | 说明       | 常见字节大小 (32位/64位) | 取值范围 (典型情况)                |
|--------------|------------|--------------------------|-------------------------------------|
| char       | 字符/整型  | 1 字节 (8位)             | -128 ~ 127 (有符号) / 0 ~ 255 (无符号) |
| short      | 短整型     | 2 字节                   | -32,768 ~ 32,767                   |
| int        | 整型       | 4 字节                   | -2,147,483,648 ~ 2,147,483,647     |
| long       | 长整型     | 4 字节 (32位系统) / 8 字节 (64位系统) | 取决于平台                         |
| long long  | 长长整型   | 8 字节                   | -9,223,372,036,854,775,808 ~ 9,223,372,036,854,775,807 |
| float      | 单精度浮点 | 4 字节                   | ~6-7 位有效数字                    |
| double     | 双精度浮点 | 8 字节                   | ~15-16 位有效数字                  |
| _Bool/bool | 布尔型   | 1 字节                   | 0（假）或 1（真）                  |


示例：
```c
int count = 100;
double ratio = 0.618;
char letter = 'A';
_Bool is_valid = 1; // C99 布尔
```

## 4. 类型修饰与范围
- 有符号/无符号：`signed` / `unsigned`
- 宽度修饰：`short`、`long` 等
- 不同平台类型范围可能不同，建议使用 `<stdint.h>` 中的固定宽度类型：
  - `int8_t`、`uint16_t`、`int32_t`、`uint64_t` 等

## 5. 类型转换（Type Casting）
显式转换可改变表达式的类型，但需注意精度与溢出风险。
```c
double d = 3.14;
int i = (int)d;    // 转换为整型，结果为 3
```

## 6. 常见实践建议
- 使用 `const` 修饰不应被修改的参数与全局配置
- 选择合适的类型以匹配数据范围与性能
- 统一命名与作用域规则，减少可变状态
- 使用固定宽度类型编写跨平台代码

## 参考
- C语言标准：C99 / C11
- 固定宽度类型：`#include <stdint.h>`
- 编码规范：Google C Style、MISRA C
