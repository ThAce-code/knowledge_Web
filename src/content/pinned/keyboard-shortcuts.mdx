# 提高效率：电脑常用快捷键

使用键盘快捷键可以显著提高你的工作效率，减少对鼠标的依赖。

## 通用核心快捷键

这些快捷键在Windows和macOS（使用***Cmd***键代替***Ctrl***）以及大多数应用程序中都适用。

| 快捷键 | 功能 |
| :--- | :--- |
| Ctrl + C | 复制选中的内容 |
| Ctrl + V | 粘贴剪贴板中的内容 |
| Ctrl + X |剪切选中的内容 |
| Ctrl + Z | 撤销上一步操作 |
| Ctrl + Y | 重做（恢复撤销的操作） |
| Ctrl + A | 全选当前页面或文档中的所有内容 |
| Ctrl + S | 保存当前文件 |
| Ctrl + F | 在当前页面或文档中查找 |
| Ctrl + P | 打印当前页面或文档 |

## Windows 系统级快捷键

| 快捷键 | 功能 |
| :--- | :--- |
| Win + D | 显示或隐藏桌面 |
| Win + E | 打开文件资源管理器 |
| Win + L | 锁定电脑 |
| Win + Tab | 打开任务视图（时间线） |
| Alt + Tab | 在打开的窗口之间切换 |
| Ctrl + Shift + Esc | 直接打开任务管理器 |
| Win + . (句号) | 打开表情符号和符号面板 |
| Win + Shift + S | 区域截图工具 |

## macOS 系统级快捷键

| 快捷键 | 功能 |
| :--- | :--- |
| Cmd + Space | 打开Spotlight搜索 |
| Cmd + Tab | 在打开的应用之间切换 |
| Cmd + Q | 退出当前应用程序 |
| Cmd + W | 关闭当前窗口 |
| Cmd + Option + Esc | 强制退出应用程序 |
| Cmd + Shift + 3 | 截取整个屏幕 |
| Cmd + Shift + 4 | 区域截图 |

## 文本编辑快捷键

这些在处理文本时非常有用。

| 快捷键 | 功能 |
| :--- | :--- |
| Ctrl + B | **加粗** |
| Ctrl + I | *斜体* |
| Ctrl + U | <u>下划线</u> |
| Ctrl + ←/→ | 按单词移动光标 |
| Shift + ←/→/↑/↓ | 选中文字 |
| Ctrl + Shift + ←/→ | 按单词选中文字 |
| Home / End | 移动光标到行首/行尾 |
