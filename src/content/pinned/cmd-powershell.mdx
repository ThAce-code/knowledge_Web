# CMD 与 PowerShell 介绍

在Windows系统中，命令行界面是与操作系统交互的强大工具。最常见的两个是命令提示符(CMD)和PowerShell。

## 命令提示符 (CMD)

CMD (Command Prompt) 是Windows传统的命令行解释器，自DOS时代以来就存在。

- **优点**: 简单、轻量，兼容老的批处理脚本(.bat)。
- **缺点**: 功能有限，命令语法不够统一，缺乏现代脚本能力。
- **应用场景**: 执行简单的系统命令、运行旧的脚本、进行网络诊断（如 ping, ipconfig）。

### 常用CMD命令

| 命令 | 描述 | 示例 |
|------|------|------|
| dir | 列出目录内容 | dir |
| cd | 切换目录 | cd C:\Users |
| cls | 清屏 | cls |
| del | 删除文件 | del file.txt |
| copy | 复制文件 | copy source.txt dest.txt |
| move | 移动文件 | move source.txt folder\ |
| mkdir | 创建新目录 | mkdir NewFolder |
| rmdir | 删除目录 | rmdir /s /q folder |
| type | 显示文件内容 | type file.txt |
| ping | 测试网络连接 | ping www.google.com |
| ipconfig | 查看网络配置 | ipconfig |
| tasklist | 查看进程列表 | tasklist |
| taskkill | 终止进程 | taskkill /PID 1234 |

## Windows PowerShell

PowerShell 是微软开发的现代、功能更强大的命令行shell和脚本语言。

- **优点**:
    - **面向对象**: PowerShell中的命令（称为Cmdlet）处理的是.NET对象，而不是纯文本，这使得数据处理更灵活。
    - **统一语法**: Cmdlet遵循 动词-名词 的命名规范（如 Get-Process, Set-Location），易于学习和预测。
    - **强大的脚本能力**: 支持变量、循环、函数等完整的脚本语言特性。
    - **可扩展性**: 可以访问WMI、COM、.NET Framework等系统管理接口。
- **缺点**: 相比CMD，学习曲线稍陡。

### 常用PowerShell命令

#### 系统命令

| 操作 | PowerShell命令 | 示例 |
|------|----------------|------|
| 列出进程 | Get-Process | Get-Process |
| 停止进程 | Stop-Process | Stop-Process -Name notepad |
| 获取IP地址 | Get-NetIPAddress | Get-NetIPAddress |
| 测试连接 | Test-Connection | Test-Connection www.google.com |

#### 文件和目录命令

| 操作 | PowerShell命令 | 示例 |
|------|----------------|------|
| 列出子项 | Get-ChildItem | Get-ChildItem |
| 切换位置 | Set-Location | Set-Location C:\Users |
| 删除项 | Remove-Item | Remove-Item file.txt |
| 新建目录 | New-Item -ItemType Directory | New-Item -ItemType Directory -Name NewFolder |
| 复制项 | Copy-Item | Copy-Item source.txt dest.txt |
| 移动项 | Move-Item | Move-Item source.txt folder\ |
| 获取内容 | Get-Content | Get-Content file.txt |

#### 网络和服务命令

| 操作 | PowerShell命令 | 示例 |
|------|----------------|------|
| Web请求 | Invoke-WebRequest | Invoke-WebRequest -Uri "url" -OutFile "file" |
| 解压归档 | Expand-Archive | Expand-Archive -Path archive.zip -DestinationPath folder |
| 获取事件日志 | Get-EventLog | Get-EventLog -LogName System |
| 获取服务 | Get-Service | Get-Service |
| 启动服务 | Start-Service | Start-Service -Name wuauserv |

| 操作 | CMD 命令 | PowerShell 命令 | Linux 命令 |

| 切换目录 | cd | Set-Location | cd |

| 字符串筛选 | find | Select-String | grep |
| 测试连接 | ping | Test-Connection | ping |

## PowerShell 与 Linux 命令对比

PowerShell 在跨平台支持下（尤其 PowerShell Core 7.x），可以与 Linux 命令进行对应。以下是常见操作的对比：

| Linux 命令 | PowerShell 对应 | 描述 |
|------------|-----------------|------|
| ls | Get-ChildItem | 列出目录内容 |
| cd | Set-Location | 切换目录 |
| pwd | Get-Location | 显示当前目录 |
| cp | Copy-Item | 复制文件 |
| mv | Move-Item | 移动文件 |
| rm | Remove-Item | 删除文件/目录 |
| cat | Get-Content | 显示文件内容 |
| echo | Write-Output | 输出内容 |
| ps | Get-Process | 列出进程 |
| kill | Stop-Process | 终止进程 |
| touch | New-Item | 创建文件 |
| man | Get-Help | 获取帮助 |
| grep | Select-String | 字符串匹配 |
| curl | Invoke-WebRequest | HTTP 请求 |

## 概述

| 特性 | CMD (命令提示符) | PowerShell (Windows PowerShell) |
|------|------------------|---------------------------------|
| 历史 | 基于 MS-DOS，命令行基础 | 基于 .NET Framework/Core，跨平台 |
| 命令类型 | 外部程序和内置命令 | Cmdlet（动词-名词），面向对象 |
| 脚本支持 | 批处理 (.bat/.cmd) | 完整脚本语言 (.ps1)，支持 Linux/macOS |
| 跨平台 | 仅 Windows | 支持 Windows、Linux、macOS (PowerShell Core 7.x) |
| 适用性 | 简单任务、兼容旧脚本 | 系统管理、自动化、复杂任务 |
| 扩展性 | 有限 | 访问 WMI、COM、.NET 等接口 |

对于现代Windows系统管理和自动化任务，<span class="text-red">***PowerShell***</span>是**首选工具**。而CMD则作为执行简单命令和保持旧脚本兼容性的备用选项。
