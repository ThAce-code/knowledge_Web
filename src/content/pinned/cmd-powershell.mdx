# CMD 与 PowerShell 介绍

在Windows系统中，命令行界面是与操作系统交互的强大工具。最常见的两个是命令提示符(CMD)和PowerShell。

## 命令提示符 (CMD)

CMD (Command Prompt) 是Windows传统的命令行解释器，自DOS时代以来就存在。

- **优点**: 简单、轻量，兼容老的批处理脚本(.bat)。
- **缺点**: 功能有限，命令语法不够统一，缺乏现代脚本能力。
- **应用场景**: 执行简单的系统命令、运行旧的脚本、进行网络诊断（如 `ping`, `ipconfig`）。

### 常用CMD命令
- `dir`: 列出目录内容
- `cd`: 切换目录
- `md`: 创建新目录
- `echo`: 显示消息或开关命令回显
- `ipconfig`: 查看网络配置

## Windows PowerShell

PowerShell 是微软开发的现代、功能更强大的命令行shell和脚本语言。

- **优点**:
    - **面向对象**: PowerShell中的命令（称为Cmdlet）处理的是.NET对象，而不是纯文本，这使得数据处理更灵活。
    - **统一语法**: Cmdlet遵循 `动词-名词` 的命名规范（如 `Get-Process`, `Set-Location`），易于学习和预测。
    - **强大的脚本能力**: 支持变量、循环、函数等完整的脚本语言特性。
    - **可扩展性**: 可以访问WMI、COM、.NET Framework等系统管理接口。
- **缺点**: 相比CMD，学习曲线稍陡。

### 常用PowerShell命令
- `Get-ChildItem` (别名 `ls`, `dir`): 列出目录内容
- `Set-Location` (别名 `cd`): 切换目录
- `New-Item`: 创建新文件或目录
- `Write-Output` (别名 `echo`): 输出对象或文本
- `Get-NetIPAddress`: 查看网络配置

## 总结

| 特性 | CMD | PowerShell |
| :--- | :--- | :--- |
| **核心** | 基于文本 | 基于对象 |
| **语法** | 零散，不统一 | `动词-名词`，统一 |
| **脚本能力** | 有限 (批处理) | 非常强大 |
| **适用场景** | 简单、兼容性任务 | 系统管理、自动化、复杂任务 |

对于现代Windows系统管理和自动化任务，**PowerShell是首选工具**。而CMD则作为执行简单命令和保持旧脚本兼容性的备用选项。
