# 磁盘分区基础知识

磁盘分区是将一块物理硬盘驱动器（HDD或SSD）在逻辑上划分为多个独立部分的过程。每个部分被称为一个“分区”或“卷”。

## 为什么要进行磁盘分区？

1.  **组织数据**: 可以将操作系统、应用程序和个人文件分开放置。例如，C盘装系统，D盘存文档和媒体。
2.  **安装多个操作系统**: 可以在不同分区安装Windows、Linux等多个操作系统，实现多重引导。
3.  **提高性能与安全**: 将系统与数据分开，重装系统时无需担心个人数据丢失。对某些文件系统，分区也有助于减少文件碎片。
4.  **备份与恢复**: 可以更轻松地只备份或恢复某个特定分区（如系统分区）。

## 分区方案

现代计算机主要使用两种分区方案：

- **MBR (Master Boot Record)**:
    - 老旧的标准，兼容性好。
    - 最多只支持4个主分区，或者3个主分区+1个扩展分区（扩展分区内可以创建多个逻辑分区）。
    - 单个分区最大容量限制为2TB。

- **GPT (GUID Partition Table)**:
    - 新一代标准，与UEFI BIOS配合使用。
    - 理论上可以创建无限多个分区（Windows限制为128个）。
    - 支持远超2TB的大容量硬盘。
    - 具有更好的数据冗余和恢复能力。

目前，GPT是所有现代计算机的首选分区方案。

## 文件系统

创建分区后，需要用一种**文件系统**来格式化它，以便操作系统能够存储和检索数据。

- **NTFS**: Windows系统的标准文件系统，支持大文件、权限控制和高可靠性。
- **FAT32**: 兼容性极好，几乎所有设备都支持，但单个文件不能超过4GB。常用于U盘。
- **exFAT**: FAT32的升级版，没有4GB文件大小限制，跨平台兼容性好。
- **APFS**: 苹果macOS的现代文件系统。
- **Ext4**: Linux系统的标准文件系统。

## 如何分区？

在Windows中，最简单的分区工具是系统自带的“磁盘管理”。

1.  按 `Win + X`，选择“磁盘管理”。
2.  在下方找到你想要操作的磁盘。
3.  右键点击一个有足够未使用空间的分区，选择“压缩卷”来腾出空间。
4.  在腾出的“未分配”空间上右键，选择“新建简单卷”，然后按照向导操作即可。

**警告**: 磁盘分区操作有风险，请务必在操作前备份重要数据。
