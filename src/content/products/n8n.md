# N8N 自动化工作流学习笔记

## 一、N8N 简介

N8N 是一款开源自动化工作流软件，核心功能是通过 AI 智能体自动执行人工任务，其核心价值体现在自动化（提高效率、降低成本、提升准确性，尤其适合重复任务）和工作流（快速构建部署、降低技术门槛、可视化操作）两方面。

### 应用场景

包括客服系统 / 聊天机器人、智能邮件助手、内容生成、用户管理系统（CRM）、数据分析等。

### 对比其他工具（如 Zapier、Make.com）的优势

- **灵活性**：支持节点数据传输转换、自由调用 API、自定义节点和代码、自由触发工作流。
- **开源特性**：可选择自托管或官方云托管。自托管需自行维护，官方云托管上手简单但为订阅制；自托管又分为云服务器托管和本地部署，本地部署需注意无公网 IP 时 Webhook 无法使用，且需保持设备开机。

## 二、N8N 部署方式

### 1. 官方云托管

通过 N8N 官网注册，可享受免费 14 天试用，适合快速上手。

### 2. 云服务器自托管

推荐使用 Elestio 部署，可选择 Hetzner 等性价比高的服务器。需注意部分服务器可能无法使用谷歌大模型，但可正常使用 GPT、DeepSeek 等模型。

### 3. 本地部署（基于 Docker Desktop）

在 Docker Desktop 中搜索 n8n 镜像并运行，需设置容器名、端口，同时配置 Volume 以备份数据。

## 三、N8N 基础理论

### 界面组成

主要包含三大列：Workflows（工作流）、Credentials（凭证）、Executions（执行记录）。

### 节点类型

- **触发节点**：用于启动工作流，包括点击触发、Schedule Trigger（定时触发）、Webhook（网络钩子）、On form submission（表单提交触发）、被其他工作流调用、接收消息、外部应用事件触发等。
- **AI 智能体**：核心节点之一，需配置选择大模型、记忆功能、外部工具、输出格式及提示词。
- **应用节点**：对接各类第三方服务，如谷歌全家桶、微软全家桶、社交媒体平台、电商工具、数据库等。

## 五、理论篇：数据结构与 API

### API 原理

以饭店为例类比：顾客（用户 / 应用）根据菜单（API 文档）告知服务员（API）需求（发送 request），服务员传达给厨房（后台系统），厨房处理后返回菜品（response）。API 作为桥梁，允许用户调取后台系统开放的功能和数据，无需关注实现细节。

### HTTP 请求组成

- **URL**：包含协议（如 https）、主机（如 example.com）、端口（如 443）、路径（如 /blog/article）、查询参数（如 ?id=123&lang=zh）。
- **method**：常用 GET（接收信息）和 POST（发送信息）。
- **header**：提供请求附加信息，如 Accept:application/json 表示要求返回 JSON 格式数据。
- **body**：仅 POST 请求包含，用于发送给服务器的信息，例如 OpenAI 图像生成的 body 需包含 model、prompt、n、size 等参数。

### N8N 数据结构

- **JSON**：键值对结构，支持嵌套，如 `{"first_name":"Tomas","location":{"city":"Paris"}}`。
- **Items**：本质是列表，每个 Item 为一个 JSON 对象，相当于表格的一行；Schema 展示表格第一行结构，用于拖拽变量时的字段选择。

## 六、数据处理技巧与节点

### 数据处理技巧

- **拖拽变量**：无需手动输入，直接拖拽上一节点的输出数据到当前节点，提高效率。
- **叠加变量**：例如拖拽 name 和 age 变量，可生成 “Tomas is 25 years old” 的 personal information 字段。

### 核心数据处理节点

- **Merge**：支持 Append（叠加多输入的 Items）、Combine（按匹配字段融合数据）、SQL Query（自定义查询）、Choose Branch（选择某一输入输出）。
- **If**：按条件将数据分为 True/False 分支处理，如年龄 > 18 走 True 分支。
- **Filter**：过滤保留符合条件的数据，如保留年龄 > 18 的 Item。
- **Aggregate**：聚合多个 Item 为一个，值为列表，例如将 3 个 Item 的 name 聚合为 `["Tomas","Jojo","Lily"]`。
- **Split Out**：拆分聚合的列表为多个独立 Item。
- **Code**：支持自定义 JS/Python 代码处理数据，需确保输出 Items 格式。
- **Limit**：限制返回 Item 数量，如仅取第一个 Item。

### PIN 技巧

用于固定节点输出，避免重复执行前面节点（如调试最后一个节点时，PIN 住上一节点输出），激活工作流时需取消 PIN，否则可能影响数据更新。

## 七、实战案例

### 案例 1：每天定时自动发推特

- 使用 Schedule Trigger 节点设置定时（如每天固定时间）。

- 连接 Twitter 节点，将生成的内容发送到推特平台。
