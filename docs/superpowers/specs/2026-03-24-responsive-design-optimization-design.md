# 响应式设计优化方案

**日期**: 2026-03-24
**状态**: 已批准
**目标分支**: develp

---

## 概述

对嵌入式知识库进行全面响应式设计优化，采用渐进式适配方案，支持手机、平板、桌面三种设备断点。

---

## 断点配置

| 断点 | 宽度 | Tailwind 前缀 |
|------|------|---------------|
| 移动端 | < 768px | 默认 |
| 平板 | 768px - 1024px | `md:` |
| 桌面 | > 1024px | `lg:` |

---

## 首页布局改动

### 左侧区块可见性

| 设备 | 行为 |
|------|------|
| 移动端 | 隐藏 |
| 平板 | 隐藏 |
| 桌面 | 显示 320px 侧边栏 |

### 移动/平板端顶部布局（新增）

顶部显示精简版组件：
- LOGO + 网站名
- 公告卡片（精简版）
- GET START 按钮
- 搜索框（全宽，垂直堆叠）

### 搜索框 + GET START 按钮

| 设备 | 布局 |
|------|------|
| 移动端 | 全宽垂直堆叠：搜索框在上，GET START 在下 |
| 平板 | 全宽垂直堆叠 |
| 桌面 | 搜索框 2/3 + GET START 1/3，水平排列 |

### 文章列表

| 设备 | 布局 |
|------|------|
| 移动端 | 单列 `grid-cols-1` |
| 平板 | 2列 `md:grid-cols-2` |
| 桌面 | 3列 `lg:grid-cols-3` |

### 具体改动

1. **移除 `h-screen`** - 避免移动端 overflow 问题
2. **`w-80` 侧边栏** - 添加 `hidden lg:block` 隐藏移动端
3. **padding 调整** - `px-12 p-12` → `px-4 py-6` (移动)，`md:px-8` (平板)，`lg:px-12` (桌面)
4. **搜索框宽度** - 移除硬编码计算，改为响应式 `w-full md:w-2/3`
5. **文章卡片间距** - 移除 `index === 1 ? 'mx-6' : ''`，使用 `gap-4 md:gap-6 lg:gap-8`

## 分类页布局改动

### 顶部导航 LOGO 位置

| 设备 | LOGO 左边距 |
|------|-------------|
| 移动端 | `ml-4` (紧凑) |
| 平板 | `md:ml-8` |
| 桌面 | `lg:ml-[calc(16rem-3rem)]` (保持现有) |

### 侧边栏

| 设备 | 宽度 | 默认状态 |
|------|------|----------|
| 移动端 | 280px | 隐藏，关闭 |
| 平板 | `md:w-52` (208px) | 显示 |
| 桌面 | `lg:w-64` (256px) | 显示 |

### 内容区 padding

| 设备 | padding |
|------|---------|
| 移动端 | `p-4` |
| 平板 | `md:p-6 lg:p-8` |
| 桌面 | `xl:p-12` |

### 具体改动

1. **侧边栏添加响应式宽度** - `w-64 md:w-52 lg:w-64`
2. **侧边栏位置** - 移动端 `absolute`，桌面 `sticky`
3. **移除脆弱的 calc 计算** - 使用标准响应式边距

## Tailwind CSS 配置

在 `app/index.css` 中确保断点配置：

```css
@theme {
  --breakpoint-sm: 640px;
  --breakpoint-md: 768px;
  --breakpoint-lg: 1024px;
  --breakpoint-xl: 1280px;
}
```

## 验收标准

1. 移动端 (< 768px) 可正常浏览所有页面
2. 平板 (768px - 1024px) 布局合理
3. 桌面 (> 1024px) 保持现有体验
4. 无横向滚动条
5. 触摸目标尺寸 >= 44px
