# Linux基础入门

Linux是一个开源的操作系统，广泛应用于服务器、嵌入式系统等领域。

## 什么是Linux

Linux是一个类Unix操作系统，具有以下特点：

- 开源免费
- 稳定可靠
- 安全性高
- 支持多用户多任务

## 常用命令

### 文件操作

- `ls` - 列出目录内容
- `cd` - 切换目录
- `pwd` - 显示当前目录
- `mkdir` - 创建目录
- `rm` - 删除文件
- `cp` - 复制文件
- `mv` - 移动文件

### 系统信息

- `uname -a` - 显示系统信息
- `top` - 显示进程信息
- `free` - 显示内存使用情况
- `df` - 显示磁盘使用情况
